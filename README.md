# SBH Hub

The Safety Builders Hub team app for Windows.

## Install
1. Open [Releases](https://github.com/jlsusvilla01-cloud/sbh-hub-download/releases/latest) and download **SBH-Hub-Setup-x.y.z.exe**.
2. Run it. If Windows shows *Windows protected your PC*, click **More info**, then **Run anyway** (the app isn't code-signed yet).
3. Sign in with your SBH account.

After that, SBH Hub updates itself.
